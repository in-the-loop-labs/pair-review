Harden thorough-tier reviews against narration-prefixed output and out-of-bounds verification, and raise the LLM JSON-extraction fallback timeout from 60 seconds to 5 minutes. Every thorough template (Levels 1-3, orchestration, consolidation) now closes with a reply-shape guard — the reply is the JSON object alone, its first character `{` — since agentic models can narrate their process ahead of the JSON and break extraction. The guard deliberately does not quote an example of the forbidden preamble: an earlier version did, and eval showed the model emitting the quoted sentence near-verbatim. The verification rules in the analysis levels and the adversarial-verification section now explicitly permit empirical verification — running the project's tests or binaries, or a reviewer-authored scratch script — under a leave-no-trace contract: repository files and git state must be exactly as found, scratch work goes in a temp directory outside the repository (or is deleted before finishing where only the repository is writable), and nothing may publish, deploy, send, or write beyond the machine. The permission is environment-conditional so the prompt never conflicts with provider-enforced restrictions: whatever the provider's flags deny stays denied, and the prompt instructs the reviewer to take a denial as final and fall back to verification by reading. Empirical runs are the strongest refutation evidence, and eval showed that banning them cost confirmed defects. The Antigravity analysis directive now defers access rules to the task instructions instead of hardcoding a read-only rule that contradicted them. The extraction timeout raise keeps large (100KB+) analyses recoverable instead of discarding them mid-extraction; the Antigravity extraction budget (`--print-timeout`) moves in step so agy still self-terminates just before the outer cap.
