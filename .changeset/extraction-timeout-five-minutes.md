Harden thorough-tier reviews against narration-prefixed output and out-of-bounds verification, and raise the LLM JSON-extraction fallback timeout from 60 seconds to 5 minutes. Every thorough template (Levels 1-3, orchestration, consolidation) now closes with a reply-shape guard — the reply is the JSON object alone, with a concrete example of the observed narration preamble — since agentic models can narrate their process ahead of the JSON and break extraction. The read-only rules in the analysis levels and the adversarial-verification section now explicitly forbid executing the project's code, tests, or binaries and creating scratch or temp space ("verify by reading code, not by running it"); the earlier "no write commands" wording left running code as a loophole. The extraction timeout raise keeps large (100KB+) analyses recoverable instead of discarding them mid-extraction; the Antigravity extraction budget (`--print-timeout`) moves in step so agy still self-terminates just before the outer cap.
