Redesign the Thorough-tier review prompts for frontier reasoning models. All five thorough prompts (Level 1-3, orchestration, consolidation) now require a verification standard — bug findings must state a concrete failure scenario and survive a refutation attempt before being reported — and carry an explicit do-not-report list to suppress false positives. Category-definition tutoring and reasoning-encouragement boilerplate are removed, focus areas are compressed into prioritized hunting lists, confidence has one unified meaning across the pipeline (probability the finding is real, set by verification performed, no score arithmetic), Level 1's contradictory scope instructions are resolved, Level 2 treats file conventions as evidence rather than authority, and orchestration scales output to the PR instead of targeting a fixed suggestion count. Security is listed first in every hunt list, and security findings are reported as attack scenarios — who can exploit it, how, and what they gain, with the code-level fix in the suggestion field — with a hardening lane for issues that lack a current attack path; orchestration and consolidation preserve the exploit framing when merging. Over-engineering (single-use abstractions, speculative generality, duplicate mechanisms) is an explicit hunting target at every level, gated by a falsifiability bar: simplicity findings must sketch the concrete simpler equivalent or be dropped as style preference.
