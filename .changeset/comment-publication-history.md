Record each comment posted to GitHub separately from its active or dismissed lifecycle. Restoring a dismissed posted comment no longer queues it for another submission, and Clear All keeps posted comments. Posted indicators link to the GitHub comment (or review), and drafts submitted or discarded directly on GitHub reconcile on reload.

Existing posted comments are backfilled with approximate review links. Comments dismissed before this upgrade cannot be backfilled because their old posted status was already lost. Review history browsing and explicit re-posting are coming separately.
