The home page now focuses the PR URL input on load (or the directory path input when the Local Reviews tab is restored), so you can paste and press Enter without clicking the field first. Focus is left alone if you have already clicked into something else while the page loads. The help modal now takes focus when it opens and returns it to where it was when it closes, so first-time users no longer type into the input hidden behind it.
